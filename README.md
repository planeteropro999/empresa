# Módulo de Gestión Empresarial - Java Profesional (Semana 1)

Pequeño sistema de administración de empleados desarrollado en Java, aplicando prácticas de programación orientada a objetos.

## Competencias Aplicadas
- Programación Orientada a Objetos y uso de Interfaces.
- Manejo de Colecciones.
- Procesamiento de datos mediante **Streams API** y **Lambdas**.
- Uso de `Optional` para prevenir nulos.
- Excepciones personalizadas y validaciones de negocio.
- Pruebas unitarias básicas con JUnit.

## Requisitos de Ejecución
- Java JDK 21 o superior.
- Maven o Gradle (opcional, para la gestión de dependencias de los tests).
